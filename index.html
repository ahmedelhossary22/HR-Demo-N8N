03 / HOW IT WORKS

Four n8n workflows behind the page

Each action on this page triggers its own workflow.

  1. Ask HR: chat workflow

    A chat webhook receives your question. An AI agent searches the HR policy knowledge base and replies with the answer and its source.

  2. Get coached: coaching workflow

    A public form sends your answers to an AI model that scores them and returns a structured coaching report.

  3. Apply: application workflow

    A public form collects the application, validates it and stores it for the HR team.

  4. Policy upload: admin workflow

    HR adds or updates policy documents in a private form. It is not exposed on this website.

ASK HR CHAT

Ask HR chat: policy answers with a source

An AI assistant that answers employee questions about leave, remote work and company rules, using only the HR policy documents HR has uploaded. If the documents do not contain the answer, it sends the employee to HR instead of guessing.

What I built

  • Chat flow: a public chat trigger passes each question to an AI agent with a strict rules prompt and an exact fallback message.
  • Retrieval: the agent searches a vector store of the policy documents before it answers, so every answer is grounded in the files.
  • Memory: each visitor has a session, so follow-up questions keep their context.
  • Policy upload flow: a private form takes a TXT, DOCX or PDF, splits it into chunks, turns them into embeddings and stores them for search.

To use it: import the file, add your own Gemini and model credentials, upload your policies with the upload form, and set Allowed Origins in the Chat Trigger to your website address. The in-memory vector store is cleared when n8n restarts, so upload the policies again after a restart.

INTERVIEW COACHING

Interview coaching: a team of AI agents

A candidate submits a job description and a CV and receives a coaching report by email: how well the CV matches, a tailored cover letter and likely interview questions with model answers.

What I built

  • Form and CV reading: a public form collects name, email, job description and CV; an AI model reads the CV file into text.
  • Orchestrator: a Career Coach agent runs three specialist agents in a fixed order and passes results between them.
  • Specialists: CV Matcher (score out of 100, strengths and gaps), Cover Letter Writer (under 230 words, facts from the CV only) and Interview Coach (five questions with short model answers).
  • Quality check and delivery: a code step confirms all three sections exist, the report is converted from Markdown to HTML and sent with Gmail.

To use it: import the file and connect your own Gemini and Gmail credentials. The CV Read and Prepare nodes no longer hold sample data, so run the form once to test it.

JOB APPLICATION

Job application: validated intake to Drive and Sheets

A public application form that checks every submission, blocks duplicates and files the CV and the details for the HR team.

What I built

  • Form: full name, email, position (dropdown), CV upload and a short motivation.
  • Validation: a code step checks the name, email format, allowed position, motivation length and that a CV file is attached; mistakes show a clear message to fix.
  • Duplicate check: the sheet is read and the same email applying for the same position shows an "already applied" message.
  • Storage: the CV is uploaded to Google Drive with a dated file name, a row is added to a Google Sheet and the applicant sees a confirmation.

To use it: import the file, connect your Google Drive and Google Sheets credentials, then replace YOUR_GOOGLE_SHEET_ID and YOUR_DRIVE_FOLDER_ID with your own sheet and folder.
